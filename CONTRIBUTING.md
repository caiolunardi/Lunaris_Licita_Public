# Como contribuir

1. Abra uma issue descrevendo o problema ou a mudança proposta.
2. Crie uma branch curta e específica.
3. Faça alterações pequenas e inclua testes.
4. Execute os testes JavaScript, Python e da interface descritos no README.
5. Abra um pull request explicando comportamento, riscos, migrações e evidências.

## Dados e segurança

Use apenas dados sintéticos. Não inclua informações reais de usuários, empresas, fornecedores, órgãos públicos, valores financeiros, documentos, IDs de recursos Google/Cloudflare ou credenciais em código, fixtures, logs, screenshots ou comentários.

Não execute migrations remotas nem configure integrações de produção como parte de testes locais.
